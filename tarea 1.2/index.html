Etiqueta meta description

La etiqueta meta con name="description" añade una descripción del contenido del documento. No se muestra en la página, pero los buscadores pueden usarla como resumen en sus resultados.

Etiqueta param

La etiqueta param se escribía dentro de object para pasarle opciones. Está obsoleta y los navegadores modernos no usan este parámetro para configurar el SVG, así que no cambia la imagen ni muestra contenido propio. El SVG visible se carga con el atributo data de object.
